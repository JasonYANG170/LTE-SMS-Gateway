# 通信工作台 3.1

侧栏独立页面：网关概览、主机设备信息、SIM 概览、SIM 详情、未读短信、收件箱、发件箱、收藏夹、转发、通讯日志、备份与恢复、缓存清理、应用升级、系统设置。

## 短信与存储

收件箱合并 SIM 与主机短信，按原始 PDU / 身份 / 内容生成稳定标识，去重显示。收藏和逐条已读状态、发件记录、定时任务保存于 `workspace-data/mail-state.enc`。新转存的短信同时保留原 SIM ICCID；旧档案未包含 ICCID 时显示当前模块可提供的信息。

发件箱提供即时发送、指定日期时间的单次定时发送和原有按天周期保号。短信限定单条 70 字。任务在主机执行，浏览器关闭不影响运行；SIM 身份变化时停止原定时任务。发送中重启的任务标记“需核对”，不自动重发。发件记录从安装本版本后开始记录，包含手动、定时、保号及程序内短信转发使用的发送接口。

备份导出为 NDJSON：首行 `lte-sms-backup / schema 1`，后续包含 message、sent、metadata 记录。服务端按行写入并等待网络背压，浏览器原生下载，不使用 `response.blob()` 聚合完整文件。下载文件包含明文短信，请按需要保存。主机备份与恢复前快照加密存储。

恢复通过 2 MiB 分块上传（文件最大 128 MiB），先校验全部记录，再以去重合并方式写入主机加密档案，不向 SIM 回写、不触发短信发送或转发。可保留原串口归属或指定目标模块；恢复前生成快照。

缓存页管理主机备份、恢复 / 升级快照、历史日志、上传暂存，以及 `ui-backups` 中的历史部署快照。清理使用文件版本标识防止删除已改变的文件；当前通讯日志、运行中文件和最新部署回滚快照保留。SIM 转存、清空、主机短信清空及自动转存阈值位于同页；直接清空前保存短信备份。

## SIM 与主机

SIM 详情自动执行只读 AT 查询，展示各指令原始响应、支持状态和解析字段：ICCID、IMSI、IMEI（模块标识）、本机号码、PIN 状态、运营商、信号、短信中心、短信服务、网络注册、APN、短信槽位、电话簿容量、固件与网络时间。不读取 PIN / PUK 密钥、Ki 或受保护的运营商文件；未提供的值不作推断。非 460 MCC 的 MNC 长度不自动猜测。

查询期间同模块发件被拒绝，普通读取指令延后执行，查询结束后恢复。通讯日志保存原始收发及事件，单文件到 8 MiB 轮转，页面显示最近 1000 条。

参考 AT 资料：[Quectel AT 指令文档](https://www.quectel.com/content/uploads/2021/03/Quectel_EP06EG06EM06_AT_Commands_Manual_V1.0.pdf)。各模块实现不同，因此 UI 隐藏明确不支持的项目，保留其他查询状态及原始数据。

## 应用升级

执行 `npm run package:update` 生成 `dist/LTE-SMS-Gateway-update.json`，包含允许列表中的后端及前端文件。安装前验证路径、SHA-256 和 JavaScript 语法，保存回滚快照。SHA-256 提供完整性校验，不是发布者签名；仅导入可信包。在线检查固定 GitHub 仓库的 Release，只有存在同名兼容包才允许安装；不会直接安装仓库源码 ZIP。

`gateway-config.json` 不包含在升级包内，示例：

```json
{"port":5823,"restartScript":"/absolute/path/restart-workspace.sh"}
```

含后端的升级需要主机管理员配置重启脚本。一键部署使用 systemd 自动重启，其他部署可配置符合主机进程管理方式的脚本，端口、依赖、账号、转发、保号、短信和工作台数据保留。维护 / 发件任务运行期间拒绝升级。纯前端升级不重启；后端升级会中断网页会话，需要重新登录。

## 验证

- `npm run test:workspace`：鉴权、收藏 / 已读、备份流、恢复去重、完整校验、分块偏移、定时任务与取消、SIM 解析、日志、缓存版本及锁定、主机信息、升级路径 / 哈希 / 语法、重启状态保留。
- `npm run test:ui`：所有独立页面、短信内容安全显示、收藏与阅读、表单保留、SIM 查询、主题和 1440 / 390 px 布局。

隔离测试使用本地模拟串口，不发送真实短信。正式设备的收发、转发与定时执行需要使用实际业务验证；部署验收只执行读取与备份下载。

## 3.1.0

- SIM 详情在模块就绪后自动采集，15 分钟缓存；隐藏不支持的指令，不重复查询同一卡已确认不支持的项。
- 本机号码由 AT+CNUM 读取，以 ICCID 关联收件短信和加密持久缓存；换卡不沿用上一张卡的号码。SIM 未写入号码时显示未提供，并支持在详情页补充号码；补充值按 ICCID 加密存放在主机，不写入 SIM。
- 登录页与工作台支持中文 / English，浏览器保存语言偏好；界面切换重载页面。短信正文与原始日志保持原样。
- 自动查询、号码缓存与换卡、双语页面及手机布局通过隔离测试。
